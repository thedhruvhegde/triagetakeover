Takeover Triage · visual language v0.1

Warm ground, loud state.

A cream canvas and near-black controls keep the screens calm inside Jira. Saturated colour is reserved for state: a likely regression, a novel event, a coverage gap. Every coloured surface also carries a text label, so colour is never the only signal. Everything below is an illustrative mock using the synthetic demo fleet. It is not a screenshot of the running app.

Dark mode follows Jira's theme in the app.

Rules
Colour is stateSaturated fills mark meaning only. A card is coloured because it says "regression", "novel" or "gap", not to add variety.
Never colour aloneEvery state fill carries its word. Colour-blind users and screen readers get the same information.
Ink on bright fillsPink, ochre, peach, lavender and mint take near-black text for AA contrast. Only the deep teal takes white.
Evidence on every claimEach recommendation shows a confidence, a reason and linked issue keys.
Radius by role12 px controls, 16 px content cards, 24 px state cards. No shadows.
Jira firstAtlassian components underneath for keyboard and focus behaviour, restyled with these tokens. Follows Jira light and dark.
