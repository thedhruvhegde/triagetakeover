**Labels:**
- **SPIKE-xx**: unverified platform behaviour, same IDs as PRD section 13 and ARCHITECTURE section 17. Nothing marked SPIKE is claimed as fact.
- **VERIFIED / INFERRED / COMMUNITY**: carried over from the research files.
- **Likelihood (L) / Impact (I):** 1 = low, 2 = medium, 3 = high. **Score = L x I.** Scores of 6 or more are reviewed at every gate.
- **Owner:** `Dev` = the developer doing engineering work. `USER` = an action only the developer as a person can take (accounts, sites, eligibility declarations, Devpost). There is one person, so "owner" means which hat, and the date it is due.
- **Status:** `Open` (not yet mitigated), `Spiking` (a dated SPIKE decides it), `Mitigated by design` (the design already contains the fallback; watch the signal), `Monitoring` (accepted, watching), `Closed`.

## 4. Accepted residual risks

- **TWG may end up resolver-only.** If SPIKE-R1 fails inside actions, TWG appears only in the UI routing path and the bonus write-up says so. Accepted: TWG is secondary.
- **No Rovo on the clean test site.** If SPIKE-X2 shows the free developer site has no Rovo, SM-7 is verified only on the demo site, and SETUP.md says the agent needs a Rovo-enabled site.
- **Preview modules can change after submission.** We cannot control this. We can detect it weekly and keep the core working without them.
- **Cross-browser image-metric drift** if the `createImageBitmap` fallback is used. Documented as a known limitation; chips carry thresholds with margin.
- **Seed bytes are reproducible only on the pinned runtimes** (Node 22/24 in CI; the Forge `nodejs24.x` runtime). With the bit-exact math library cut (2026-11-19), another runtime (for example the browser seed fallback) may produce slightly different bytes; checks there compare engine metrics within tolerance (SEED_DATA §4.3).
- **Index freshness without background triggers.** Events written by other tools appear on the board only after someone opens their issue panel or clicks "Re-sync now" (ARCHITECTURE D12). Accepted: every demo and judge path writes through the app.
